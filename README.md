## ✨ Highlights & Features

1. **California Light Luxury & Telugu Heritage:**

   - Google Fonts typography featuring **Playfair Display**, **Cinzel Decorative**, **Plus Jakarta Sans**, and **Ramabhadra/Gidugu** for Telugu script.

2. **Authentic Photography & Warm Personal Story:**

3. **Celebration Timeline & Calendar Invite:**
   - Sleek horizontal infographic visual timeline on desktop and clean vertical track on mobile, highlighting:

5. **12 Sacred Steps of the Wedding Ceremony (కల్యాణ మహోత్సవ క్రమం):**
   - Balanced, symmetric 4×3 grid guide of sacred Vedic rites conducted in Sanskrit at the Kalyana Mandapam:
     1. Ganapathi Puja (గణపతి పూజ)
     2. Punyaha Vachana (పుణ్యాహవాచనం)

     4. Kanyadanam (కన్యాదానం - Cane weaved basket / Father's lap)
     5. Panigrahanam (పాణిగ్రహణం - "Holding hands" Grihastha vows)
     6. Subha Muhurtham: Jeelakarra & Bellam (జీలకర్ర & బెల్లం)
     7. Mangalya Dharana & Sindhur (మాంగళ్యధారణం & సింధూరం)
     8. Talambralu / Akshata Aropana (తలంబ్రాలు)
     9. Exchange of Garlands & Gold Rings (పూలదండలు & ఉంగరాల మార్పిడి)
     10. Havan / Pradhana Homam (ప్రధాన హోమం)
     11. Sapthapadi (సప్తపది - 7 Sacred Steps & Vows)
     12. Concluding Blessings: Harathi, Ashirvachanam & Arundhati Darshanam (హారతి, ఆశీర్వచనం & అరుంధతీ దర్శనం)

## 🚀 Running Locally

The website is built with clean, standards-compliant HTML5, Vanilla CSS, and modern JavaScript with zero build tools or package managers required.

To view locally:

```bash
# Using Python (recommended)
python3 -m http.server 8080
```

Then open your browser to:
`http://localhost:8080`
